Chapter 4

Типы данных
double - число с плавающей точкой
bool - true/false
char - один символ
int - целое число
void - отсутствие типа

sizeof - узнать занимаемый объем памяти переменной
unsigned - целочисленный тип без отрицательных чисел

static_cast<тип>(значение) - преобразование значения к указанному типу данных

Chapter 5

const - назначить константу
constexpr - назначить compile-time константу (значение должно быть известно во время компиляции)
std::string - строковой тип данных (библиотека - <string>)
>> - оператор, читающий данные из потока до пробела
std::getline(поток, переменная) - функция, читающая информацию из потока до \n (enter)
std::ws - манипулятор, очищает пробельные символы в начале потока
имя_строки.length() -  метод, возвращающий длину строки (без \0 в конце)
"Hello"s - (суффикс s) строковой литерал типа std::string (пространство имен - using namespace std::string_literals)
std::string_view — доступ к строке без копирования (только чтение) (библиотека - <string_view>)
"Hello"sv - (суффикс sv) строковой литерал типа std::string_view (пространство имен - using namespace std::string_view_literals)
remove_prefix(n) - метод для string_view, сдвигающая вид строки на n символов
remove_suffix(n) - метод для string_view, обрезающий вид строки на n символов справа
std::erase(name, 'символ') - убрать символ из динамического контейнера

Chapter 6

std::pow(число, степень) - функция возведения числа в степень (библиотека - <cmath>)
++x - префиксный оператор инкремента. меняет значение х на х+1
x++ - постфиксный оператор инкремента. сперва возвращает старое значение, а потом меняет значение х на х+1
--x - префиксный оператор декремента. меняет значение х на х-1
x-- - постфиксный оператор декремента. сперва возвращает старое значение, а потом меняет значение х на х-1
?: - условный (тернарный) оператор. принимает 3 операнда и возвращает одно из двух значений в зависимости от условия. синтаксис - (условие ? значение 1 : значение 2)
! - логическое "не"
|| - логическое "или"
&& - логическое "и" (имеет больший приоритет выполнения, чем ||)

Chapter 8

if constexpr() - проверка условия на этапе компиляции. условие должно быть известно сразу. неудовлетворяющая условию ветка кода вырезается полностью из кода на этапе компиляции.
switch(х) - оператор ветвления, сверяющий условия в заданных метках. оптимизированная замена if/else. работает только с целочисленными типами данных. для прекращения работы оператора обязательно нужен break или continue, иначе оператор вернет значение и выполнит все последующих метки
case х: - заданная метка. объявлять переменные внутри меток можно только внутри блоков
default - подстраховывающая метка, выполняемая при условии, что условия во всех остальных заданных метках не удовлетворены
[[fallthrough]] - атрибут, указывающий компилятору о намеренности совершения действия
goto - оператор перемещения внутри всей функции по меткам
while() - цикл, выполняющий код внутри блока до тех пор, пока условие истинно
do {...} while() - цикл, выполняющий код внутри блока минимум 1 раз даже если условие не истинно или до тех пор, пока условие истинно
for (init-statement; condition; end-expression) - цикл, выполняющий код внутри блока, пока условие condition возвращает true. init-statement - создание начальной локальной для цикла переменной, срабатывает только один раз. end-expression - изменение созданной или любой другой переменной, используемой в цикле или за ее пределами. любой частью условий выполнения цикла можно пренебречь, если того требует логика программы
break - оператор, позволяющий выйти из цикла или оператора ветвления switch
continue - оператор, позволяющий пропустить последующее выполнение цикла и вернуться к его началу с дальнейшим его выполнением
std::exit - мгновенно завершает выполнение программы из любой точки без сворачивания стека
std::atexit() - выдает программе инструкцию для действий при завершении программы любым способом, кроме внезапного или аварийного
std::abort() - аварийное завершение программы

==**Рандомайзер случайных чисел**==
(!)Не для понимания, скорее просто для копирования. Библиотека `<random>`

- static std::mt19937 x {std::random_device{}()} - генератор случайных чисел с типом данных mt19937. static заставляет объект х остаться в памяти программы после завершения функции. std::random_device{} - вызывает временный объект std::random_device и получает от него значение, которое используется как начальное значение (seed) для генератора x
- std::uniform_int_distribution y{ 1, 6 } -создание объекта равномерного целочисленного распределения `y`. Параметры `1, 6` задают диапазон (от минимального к максимальному включительно), в пределах которого распределение будет выдавать числа при вызове
- int result = y(x) - вызов инструмента у с передачей ему генератора х и сохранение сгенерированного числа в переменную result

**==Библиотека `<cctype>`==** 
(!)Работает только с типом данных char

Функции возвращают true, когда переменная x принимает значение:
- std::ispunct(x) - спецсимвола (кроме пробела)
- std::isdigit(x) - от 0 до 9
- std::isupper(x) - от A до Z
- std::islower(x) - от a до z

Функции возвращают true, когда:
- std::isspace(x) - символ является пробелом или служебным символом разделения (пробел, табуляция, перевод строки)
- std::isalnum(x) - переменная является буквой или цифрой (a-z, A-Z, 0-9)
- std::isalpha(x) - переменная является буквой (a-z, A-Z)

Функция, превращающая:
- std::toupper(x) - строчную букву x в заглавную
- std::tolower(x) - заглавную букву x в строчную

**==Chapter 5==**

Для работы с переменными:
- const - назначить константу
- constexpr - назначить compile-time константу (значение должно быть известно во время компиляции)
- std::string_view — тип данных для ссылки на строку только для ее чтения (библиотека - <string_view>)
- std::string - строковой тип данных (библиотека - `<string>`)
- "Hello"s - (суффикс s) строковой литерал типа std::string (пространство имен - using namespace std::string_literals)
- "Hello"sv - (суффикс sv) строковой литерал типа std::string_view (пространство имен - using namespace std::string_view_literals)

Методы:
- имя_строки.length() -  возвращает длину строки (без \0 в конце)
- имя_view.remove_prefix(n) - сдвигает вид строки на n символов (работает с string_view)
- имя_view.remove_suffix(n) - обрезает вид строки на n символов справа (работает с string_view)
- имя_строки.erase(x, y) - удаление символа из строки, x - индекс первого символа, y - количество символов
- имя_строки.find(x, y) - поиск символа в строке, возвращает индекс первого найденного символа x, начинает поиск с индекса y (rfind - поиск справа-налево)
- имя_строки.substr(x, y) - возвращает новую строку из старой. x - первый индекс новой строки, у - длина

Функции:
- std::getline(поток, переменная) - функция, читающая информацию из потока до \n (enter)
- std::ws - манипулятор, очищает пробельные символы в начале потока
- std::erase(name, 'символ') - функция для удаления символа из динамического контейнера

**==Chapter 6==**

- std::pow(число, степень) - функция возведения числа в степень (библиотека - `<cmath>`)
- ?: - условный оператор, принимающий 3 операнда и возвращающий одно из двух значений в зависимости от условия. синтаксис - (условие ? значение 1 : значение 2)

Операторы инкремента и декремента:
- ++x - префиксный оператор инкремента. заменяет значение х на х+1
- x++ - постфиксный оператор инкремента. сперва возвращает старое значение, а потом меняет значение х на х+1
- --x - префиксный оператор декремента. заменяет значение х на х-1
- x-- - постфиксный оператор декремента. сперва возвращает старое значение, а потом меняет значение х на х-1

Логические операторы:
- ! - логическое "не"
- || - логическое "или"
- && - логическое "и" (имеет больший приоритет выполнения, чем ||)

**==Chapter 8==**

- `[[fallthrough]]` - атрибут, указывающий компилятору о намеренности совершения действия

Операторы ветвления и работа с метками:
- switch(х) - оператор ветвления, сверяющий условия в заданных метках. оптимизированная замена if/else. работает только с целочисленными типами данных. для прекращения работы оператора обязательно нужен break, иначе оператор провалится в следующую ветку
- if constexpr() - оператор ветвления на этапе компиляции. условие должно быть известно сразу. неудовлетворяющая условию ветка кода вырезается
- case х: - заданная метка. объявлять переменные внутри меток можно только внутри блоков
- default - подстраховывающая метка, выполняемая при условии, что условия во всех остальных заданных метках не удовлетворены
- goto - оператор перемещения внутри всей функции по меткам

Циклы:
- while() - цикл, выполняющий код внутри блока до тех пор, пока условие истинно
- do {...} while() - цикл, выполняющий код внутри блока минимум 1 раз даже если условие не истинно или до тех пор, пока условие истинно
- for (init-statement; condition; end-expression) - цикл, выполняющий код внутри блока, пока условие condition возвращает true. init-statement - создание начальной локальной для цикла переменной, срабатывает только один раз. end-expression - изменение созданной или любой другой переменной, используемой в цикле или за ее пределами. любой частью условий выполнения цикла можно пренебречь, если того требует логика программы

Операторы и функции:
- break - позволяет выйти из цикла или оператора ветвления switch
- continue - позволяет пропустить последующее выполнение цикла и вернуться к его началу с дальнейшим его выполнением
- std::exit - мгновенно завершает выполнение программы из любой точки без сворачивания стека
- std::atexit() - выдает программе инструкцию для действий при завершении программы любым способом, кроме внезапного или аварийного
- std::abort() - аварийное завершение программы

**==Chapter 10==**

- static_cast<тип>(значение) - преобразование значения к указанному типу данных
- using UserNameType = тип_данных - создание пользовательского псевдонима для типа данных. по стандарту имя принято называть с заглавной буквы. используется при сокращении длинных типов или для упрощения понимания кода и т.д.
- auto x{5.0} - автоопределение типа данных по значению переменной. для автоопределения, тип данных должен быть полным и значение переменной должно быть инициализировано. сбрасывает константы и ссылки

**==Chapter 11==**

- void printInt(char) = delete - "= delete" - запрет на вход определенного типа данных на вход в функцию. работает с шаблонными функциями напрямую
- template `<typename T>` - создать шаблонную функцию, где Т - неявный тип данных. template заявляет компилятору о создании трафарета, вместо готовой строчки кода. typename - идентификатор сущности, указывающий компилятору что Т это тип данных. в шаблоне все неявные типы данных заменяются на Т и позже подставляются автоматически под тип аргумента. шаблоны, используемые в нескольких файлах, определяются в заголовочном файле
- max`<int>`(x, y) - явное указание аргумента шаблона. указывает какой тип данных должен подставить компилятор вместо неявного типа. если оставить `<>` пустыми при вызове функции, компилятор будет искать нужную функцию только среди шаблонов при перегрузке
- getSqrt`<x>`() - передать функции nontype константу x

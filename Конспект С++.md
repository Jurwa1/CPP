Help chapter

setlocale(LC_ALL, "ru") - установить русскую локализацию для консоли (библиотека - <locale>)

Chapter 1

#include <iostream> - вызов стандартной библиотеки С++
[[maybe_unused]] - атрибут, указывающий, что неиспользование допустимо
std::cout (character output) - поток вывода данных
std::endl (end line) - перенос строки + очистка буфера
\n  - перевод строки для вывода
std::cin (character input) - поток ввода

Chapter 2

namespace - вызвать локальную область
#pragma once - вызвать файл только один раз

Макросы
#define - создать макрос
#undef - убрать макрос
#ifdef - скомпилировать участок кода, если макрос определен
#ifndef - скомпилировать участок кода, если макрос не определен
#endif - конец условной компиляции
#if 0 - исключить участок кода из компиляции
#if 1 - включить участок кода в компиляцию

Chapter 3

Дебаг горячие клавиши
f5 - запуск отладки  
ctrl+f5 - запуск программы
f10 - следующая строка кода  
f11 - зайти в функцию  
shift+f11 - выйти из функции 
ctrl+f10 - выполнить до текущей строки кода
f5 (в процессе отладки) - выполнение программы до конца или следующей точки остановы
ctrl+shift+f10 - переместиться на выбранную строку
ctrl+alt+w, 1 - открытие окна для отслеживания переменных и приложений

std::cerr - вывод текста при отладке

Chapter 4

Типы данных
double - число с плавающей точкой
bool - true/false
char - один символ
int - целое число
void - отсутствие типа

sizeof - узнать занимаемый объем памяти переменной
unsigned - целочисленный тип без отрицательных чисел
std::int_fast#_t - тип с минимальной шириной # бит, оптимизирован по скорости (<библиотека> - cstdint)
std::int_least#_t - самый маленький целочисленный тип минимальной шириной # бит (библиотека - <cstdint>)
std::setprecision - манипулятор, задающий точность вывода данных числа с плавающей точкой (библиотека - <iomanip>)
std::boolalpha/std::noboolalpha - включить/выключить ввод и вывод "true" или "false", вместо "1" или "0" соответственно
std::cin.get - считывает по 1 символу из потока информации (включая пробелы)
static_cast<тип>(значение) - преобразование значения к указанному типу данных

Chapter 5

const - назначить константу
constexpr - назначить compile-time константу (значение должно быть известно во время компиляции)
std::string - строковой тип данных (библиотека - <string>)
">>" - оператор, читающий данные из потока до пробела
std::getline(поток, переменная) - функция, читающая информацию из потока до \n (enter)
std::ws - манипулятор, очищает пробельные символы в начале потока
имя_строки.length() -  метод, возвращающий длину строки (без \0 в конце)
"Hello"s - (суффикс s) строковой литерал типа std::string (пространство имен - using namespace std::string_literals)
std::string_view — доступ к строке без копирования (только чтение) (библиотека - <string_view>)
"Hello"sv - (суффикс sv) строковой литерал типа std::string_view (пространство имен - using namespace std::string_view_literals)
remove_prefix(n) - метод для string_view, сдвигающая вид строки на n символов
remove_suffix(n) - метод для string_view, обрезающий вид строки на n символов справа
